# GitHub workflow demo

A dependency-free Python greeting CLI for practicing branches, pull requests, and merges.

## Requirements

Python 3.6 or later. No packages to install.

## Usage

```sh
python hello.py
# Hello, World!
python hello.py David
# Hello, David!
python hello.py --help
```

Names containing spaces should be quoted: `python hello.py "Ada Lovelace"`.

## Workflow

Each change is developed on a branch, proposed through a pull request, and merged into main. This repository is a small public practice project.
